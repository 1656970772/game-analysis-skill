# 图片预览客户端 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 GameAnalysis 增加一个固定在 skill `tools/` 目录的本地图片预览 EXE，并让每次导出的 study-root 只生成 BAT 启动器、manifest、缩略图和错误日志，替代默认 HTML 图片画廊。固定 EXE 是必达交付，不能降级为可选项。

**Architecture:** 采用“配置 + Python 生成链路 + Electron 固定客户端”的分层架构。Python 负责配置加载、图片扫描、manifest、缩略图和 BAT；BAT 显式传入 `--study-root`、`--manifest`，并根据 manifest `source_roots` 重复传入 `--images-root`；Electron 客户端只读加载传入的 manifest，先校验 CLI 图片根与 manifest 图片根完全一致，再通过本地白名单资源协议预览图片，不在运行时递归扫描任意磁盘。

**Viewer interaction contract:** 点击卡片打开预览覆盖层；鼠标滚轮缩放图片；按住鼠标左键拖拽平移图片；预览仅通过右上角 X/关闭按钮或 Esc 关闭；`打开目录` 按钮通过系统文件管理器打开并定位当前图片；右键不触发操作，不属于默认工作流。

**Tech Stack:** Python 3 + pytest、Pillow、PowerShell 5.1+、Electron、electron-builder、Windows BAT。

---

## 任务契约

用户目标：在 GameAnalysis skill 目录中沉淀一个图片预览客户端工具；GameAnalysis 每次导出图片后，在输出项目中生成一个 BAT，双击 BAT 即可浏览这次导出的图片；固定 EXE 放在 skill `tools/` 目录，避免每次重新 build EXE，并替代当前 HTML 画廊默认流程。

非目标和边界：

- 不上传、发布、出售、打包分发第三方原始图片资源。
- 不修改源游戏目录。
- 不删除旧 HTML 画廊脚本；只把它降级为兼容/应急路径。
- 不把项目名、图片名、输出路径或工具路径写成全局默认。
- BAT 可写入本机当前 skill EXE 绝对路径和本次 manifest 中声明的图片根，这是生成时的本机入口，不是跨机器分发承诺。

验收标准：

- `built-in-tools/GameImageGallery_1.0.0/GameImageGallery.exe` 是固定工具目标路径，必须在验收时存在；如果已存在则验证现有 EXE，否则运行构建脚本生成。
- 固定 EXE 必须通过 `--self-test --study-root ... --manifest ... --images-root ...` 烟测。Node/npm 不可用且没有可验证的固定 EXE 时，任务状态必须为 BLOCKED，不能宣称完成。
- `<study-root>/2.报告/打开图片画廊.bat` 可由脚本生成，并显式传入本次 `study-root`、manifest，以及 manifest `source_roots` 中每个图片根对应的重复 `--images-root`。
- `<study-root>/4.临时目录/中间索引/图片画廊/manifest.json` 包含图片条目、缩略图路径和错误摘要。
- 缩略图为 `.png`，写入 `4.临时目录/中间索引/图片画廊/thumbnails/`。
- 默认扫描 `1.分类资源/图片/`，可通过配置或命令行增加其他图片根。
- Electron 源不硬编码 `全量图片画廊.html`，不依赖每项目 EXE 构建，并校验 CLI `--images-root` 集合与 manifest `source_roots[].path` 集合完全一致后才放行。
- `SKILL.md`、`directory-spec.md`、workflow、GameMaker workflow、multi-agent prompt 和测试期望同步迁移到 BAT + manifest 默认入口。

失败标准：

- 默认流程仍要求生成 `2.报告/全量图片画廊.html`。
- 默认流程仍要求每个 study-root 运行 `npm install` 或 `npm run dist`。
- 实施计划把固定 EXE 构建、EXE 存在验证或 EXE self-test 写成 optional。
- Node/npm 不可用且没有固定 EXE 时继续把任务标记为完成。
- BAT 只传 `--study-root` 和 `--manifest`，没有按 manifest `source_roots` 重复传入 `--images-root`。
- Electron 直接信任 manifest `source_roots`，没有校验 CLI 图片根与 manifest 图片根一致。
- Python、Electron 或 BAT 写死某个游戏名、某个导出目录或某张图片名。
- Manifest、缩略图、错误日志写入 `2.报告/` 或 study-root 根目录。
- 把提交作为每个任务必做步骤；版本库集成只能在用户明确要求时作为最终集成选项执行。

```python
from __future__ import annotations

import hashlib
import json
from dataclasses import dataclass
from pathlib import Path
from typing import Any


CONFIG_RELATIVE_PATH = Path("references") / "image-gallery-viewer-config.json"


@dataclass(frozen=True)
class GalleryPaths:
    report_dir: Path
    index_dir: Path
    manifest: Path
    errors_jsonl: Path
    thumbnails_dir: Path
    launcher: Path


def load_config(skill_root: Path) -> dict[str, Any]:
    config_path = skill_root / CONFIG_RELATIVE_PATH
    with config_path.open("r", encoding="utf-8") as handle:
        config = json.load(handle)
    required_top_level = ["tool", "launcher", "paths", "default_image_roots", "image_extensions", "thumbnail", "manifest", "ui"]
    missing = [key for key in required_top_level if key not in config]
    if missing:
        raise ValueError(f"image gallery config missing keys: {', '.join(missing)}")
    return config


def as_path(value: str) -> Path:
    return Path(value.replace("/", "\\"))


def gallery_paths(study_root: Path, config: dict[str, Any]) -> GalleryPaths:
    paths = config["paths"]
    report_dir = study_root / as_path(paths["report_dir"])
    index_dir = study_root / as_path(paths["index_dir"])
    launcher_name = config["launcher"]["bat_name"]
    return GalleryPaths(
        report_dir=report_dir,
        index_dir=index_dir,
        manifest=index_dir / paths["manifest_name"],
        errors_jsonl=index_dir / paths["errors_name"],
        thumbnails_dir=index_dir / paths["thumbnails_dir"],
        launcher=report_dir / launcher_name,
    )


def stable_id(source_label: str, relative_path: str, size_bytes: int) -> str:
    payload = f"{source_label}\n{relative_path}\n{size_bytes}".encode("utf-8")
    return hashlib.sha1(payload).hexdigest()[:16]


def resolve_image_roots(
    study_root: Path,
    config: dict[str, Any],
    extra_roots: list[Path],
) -> list[tuple[str, Path]]:
    roots: list[tuple[str, Path]] = []
    for item in config["default_image_roots"]:
        candidate = study_root / as_path(item["relative_path"])
        if candidate.is_dir():
            roots.append((item["label"], candidate))
    for index, root in enumerate(extra_roots, start=1):
        resolved = root.resolve()
        if resolved.is_dir():
            roots.append((f"自定义图片根{index}", resolved))
    return roots


def ensure_inside(path: Path, root: Path) -> bool:
    try:
        path.resolve().relative_to(root.resolve())
        return True
    except ValueError:
        return False


def write_json(path: Path, data: dict[str, Any]) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")
```

from __future__ import annotations

import argparse
import json
from datetime import datetime, timezone
from pathlib import Path
from typing import Any

from PIL import Image, ImageDraw

try:
    import image_gallery_common as gallery_common
except ModuleNotFoundError:
    from scripts import image_gallery_common as gallery_common


def iter_image_files(root: Path, extensions: set[str]) -> list[Path]:
    return sorted(
        [path for path in root.rglob("*") if path.is_file() and path.suffix.lower() in extensions],
        key=lambda path: path.relative_to(root).as_posix().lower(),
    )


def category_for(relative_path: str) -> str:
    parts = Path(relative_path).parts
    return parts[0] if len(parts) > 1 else "未分类"


def checkerboard(size: tuple[int, int], dark: str, light: str, cell: int) -> Image.Image:
    image = Image.new("RGB", size, dark)
    draw = ImageDraw.Draw(image)
    for y in range(0, size[1], cell):
        for x in range(0, size[0], cell):
            color = light if ((x // cell) + (y // cell)) % 2 else dark
            draw.rectangle((x, y, x + cell - 1, y + cell - 1), fill=color)
    return image


def make_thumbnail(src: Path, dst: Path, thumb_config: dict[str, Any]) -> bool:
    if dst.exists() and dst.stat().st_size > 0:
        return False
    dst.parent.mkdir(parents=True, exist_ok=True)
    max_size = int(thumb_config["max_size"])
    with Image.open(src) as opened:
        has_alpha = opened.mode in {"RGBA", "LA"} or "transparency" in opened.info
        image = opened.convert("RGBA")
        image.thumbnail((max_size, max_size), Image.Resampling.LANCZOS)
        canvas = checkerboard(
            (max_size, max_size),
            thumb_config["checker_dark"],
            thumb_config["checker_light"],
            int(thumb_config["checker_cell"]),
        )
        x = (max_size - image.width) // 2
        y = (max_size - image.height) // 2
        canvas.paste(image, (x, y), image if has_alpha else None)
        canvas.save(dst, thumb_config["format"])
    return True


def image_item(
    path: Path,
    source_label: str,
    source_root: Path,
    thumbnails_dir: Path,
    thumb_config: dict[str, Any],
) -> tuple[dict[str, Any], bool]:
    relative_path = path.relative_to(source_root).as_posix()
    size_bytes = path.stat().st_size
    item_id = gallery_common.stable_id(source_label, relative_path, size_bytes)
    thumb_path = thumbnails_dir / f"{item_id}.png"
    with Image.open(path) as opened:
        width, height = opened.size
        mode = opened.mode
        has_alpha = opened.mode in {"RGBA", "LA"} or "transparency" in opened.info
    created = make_thumbnail(path, thumb_path, thumb_config)
    return (
        {
            "id": item_id,
            "name": path.name,
            "source_label": source_label,
            "source_path": str(path.resolve()),
            "relative_path": relative_path,
            "category": category_for(relative_path),
            "width": width,
            "height": height,
            "mode": mode,
            "has_alpha": bool(has_alpha),
            "size_bytes": size_bytes,
            "modified_time": datetime.fromtimestamp(path.stat().st_mtime, timezone.utc).isoformat(),
            "thumbnail_path": str(thumb_path.resolve()),
            "status": "ready",
        },
        created,
    )


def build_manifest(
    study_root: Path,
    skill_root: Path,
    extra_image_roots: list[Path],
    title: str | None = None,
) -> dict[str, Any]:
    config = gallery_common.load_config(skill_root)
    paths = gallery_common.gallery_paths(study_root, config)
    paths.index_dir.mkdir(parents=True, exist_ok=True)
    paths.thumbnails_dir.mkdir(parents=True, exist_ok=True)
    roots = gallery_common.resolve_image_roots(study_root, config, extra_image_roots)
    extensions = {extension.lower() for extension in config["image_extensions"]}
    items: list[dict[str, Any]] = []
    errors: list[dict[str, str]] = []
    created_count = 0
    for source_label, source_root in roots:
        for image_path in iter_image_files(source_root, extensions):
            try:
                item, created = image_item(image_path, source_label, source_root, paths.thumbnails_dir, config["thumbnail"])
                items.append(item)
                if created:
                    created_count += 1
            except Exception as exc:
                errors.append(
                    {
                        "source_label": source_label,
                        "path": str(image_path),
                        "error": str(exc),
                    }
                )
    manifest = {
        "schema_version": int(config["manifest"]["schema_version"]),
        "tool": {
            "name": config["tool"]["name"],
            "version": config["tool"]["version"],
        },
        "study_root": str(study_root.resolve()),
        "generated_at": datetime.now(timezone.utc).isoformat(),
        "title": title or f"{study_root.name} 图片画廊",
        "ui": config["ui"],
        "source_roots": [{"label": label, "path": str(root.resolve())} for label, root in roots],
        "items": items,
        "summary": {
            "item_count": len(items),
            "failed_count": len(errors),
            "thumbnail_count_created": created_count,
        },
    }
    gallery_common.write_json(paths.manifest, manifest)
    max_errors = int(config["manifest"]["max_error_records"])
    paths.errors_jsonl.write_text(
        "".join(json.dumps(error, ensure_ascii=False) + "\n" for error in errors[:max_errors]),
        encoding="utf-8",
    )
    return manifest["summary"] | {"manifest": str(paths.manifest)}


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("--study-root", required=True)
    parser.add_argument("--skill-root", default=str(Path(__file__).resolve().parents[1]))

    parser.add_argument("--title", default=None)

    result = build_manifest(

        Path(args.skill_root).resolve(),
        [Path(value).resolve() for value in args.image_root],

    )
    print(json.dumps(result, ensure_ascii=False))
    return 0

def image_roots_from_manifest(manifest_path: Path) -> list[Path]:
    manifest = json.loads(manifest_path.read_text(encoding="utf-8"))

    for item in manifest.get("source_roots", []):

        for index in range(1, len(image_roots) + 1)

setlocal
set "STUDY_ROOT={study_root}"
set "SKILL_ROOT={skill_root}"

const { app, BrowserWindow, ipcMain, protocol, shell, clipboard, session } = require("electron");
const fs = require("fs");
const path = require("path");
const { pathToFileURL } = require("url");

let mainWindow = null;
let runtime = null;

function argValue(name) {
  const values = argValues(name);
  return values.length ? values[0] : "";
}

function argValues(name) {
  const values = [];
  for (let index = 0; index < process.argv.length; index += 1) {
    if (process.argv[index] === name && index + 1 < process.argv.length) {
      values.push(process.argv[index + 1]);
    }
  }
  return values;
}

function canonicalPath(value) {
  const resolved = path.resolve(value);
  try {
    return fs.realpathSync.native(resolved);
  } catch {
    return resolved;
  }
}

function normalizeForCompare(value) {
  const resolved = canonicalPath(value);
  return process.platform === "win32" ? resolved.toLowerCase() : resolved;
}

function sameRootSet(left, right) {
  const leftSet = new Set(left.map(normalizeForCompare));
  const rightSet = new Set(right.map(normalizeForCompare));
  return leftSet.size === rightSet.size && [...leftSet].every((item) => rightSet.has(item));
}

function isInsideRoot(localPath, root) {
  const resolved = canonicalPath(localPath);
  const allowed = canonicalPath(root);
  const allowedWithSep = allowed.endsWith(path.sep) ? allowed : allowed + path.sep;
  return resolved === allowed || resolved.startsWith(allowedWithSep);
}

function resolveRuntime() {
  const studyRootArg = argValue("--study-root");
  if (!studyRootArg) {
    throw new Error("Missing required --study-root argument");
  }
  const manifestArg = argValue("--manifest");
  if (!manifestArg) {
    throw new Error("Missing required --manifest argument");
  }
  const studyRoot = canonicalPath(studyRootArg);
  const manifestPath = canonicalPath(manifestArg);
  const cliImageRoots = argValues("--images-root").map((root) => canonicalPath(root));
  if (!manifestPath || !fs.existsSync(manifestPath)) {
    throw new Error(`Cannot find manifest: ${manifestPath}`);
  }
  if (!isInsideRoot(manifestPath, studyRoot)) {
    throw new Error(`Manifest must be inside study root: ${manifestPath}`);
  }
  const manifest = JSON.parse(fs.readFileSync(manifestPath, "utf8"));
  const manifestImageRoots = (manifest.source_roots || [])
    .map((root) => root.path)
    .filter(Boolean)
    .map((root) => canonicalPath(root));
  if (!cliImageRoots.length) {
    throw new Error("Missing required --images-root argument");
  }
  if (!sameRootSet(cliImageRoots, manifestImageRoots)) {
    throw new Error("manifest image roots do not match CLI --images-root values");
  }
  const galleryIndexRoot = canonicalPath(path.join(studyRoot, "4.临时目录", "中间索引", "图片画廊"));
  validateManifestItems(manifest, cliImageRoots, galleryIndexRoot);
  const allowedRoots = new Set([studyRoot, path.dirname(manifestPath), galleryIndexRoot, ...cliImageRoots]);
  return {
    studyRoot,
    manifestPath,
    manifest,
    allowedImageRoots: cliImageRoots,
    allowedThumbnailRoot: galleryIndexRoot,
    allowedRoots: Array.from(allowedRoots)
  };
}

function isInsideAny(localPath, roots) {
  const resolved = path.resolve(localPath);
  return roots.some((root) => isInsideRoot(resolved, root));
}

function isAllowedImage(localPath) {
  return isInsideAny(localPath, runtime.allowedImageRoots);
}

function isAllowedThumbnail(localPath) {
  return isInsideRoot(localPath, runtime.allowedThumbnailRoot);
}

function validateManifestItems(manifest, imageRoots, thumbnailRoot) {
  for (const item of manifest.items || []) {
    if (item.source_path && !isInsideAny(item.source_path, imageRoots)) {
      throw new Error(`manifest item source_path escapes allowed image roots: ${item.id || item.source_path}`);
    }
    if (item.thumbnail_path && !isInsideRoot(item.thumbnail_path, thumbnailRoot)) {
      throw new Error(`manifest item thumbnail_path escapes gallery index root: ${item.id || item.thumbnail_path}`);
    }
  }
}

function itemById(id) {
  return (runtime.manifest.items || []).find((item) => item.id === id);
}

function pathForAsset(kind, id) {
  const item = itemById(id);
  if (!item) return null;
  const selected = kind === "thumb" ? item.thumbnail_path : item.source_path;
  if (!selected) return null;
  if (kind === "thumb" && !isAllowedThumbnail(selected)) return null;
  if (kind !== "thumb" && !isAllowedImage(selected)) return null;
  return selected;
}

function registerProtocols() {
  protocol.handle("ga-image", async (request) => {
    const url = new URL(request.url);
    const kind = url.hostname;
    const id = decodeURIComponent(url.pathname.replace(/^\/+/, ""));
    const localPath = pathForAsset(kind, id);
    if (!localPath || !fs.existsSync(localPath)) {
      return new Response("missing image", { status: 404 });
    }
    return new Response(fs.readFileSync(localPath));
  });
}

function installNetworkBlocker() {
  session.defaultSession.webRequest.onBeforeRequest(
    { urls: ["http://*/*", "https://*/*"] },
    (_details, callback) => callback({ cancel: true })
  );
}

function createWindow() {
  mainWindow = new BrowserWindow({
    width: 1440,
    height: 980,
    minWidth: 920,
    minHeight: 640,
    title: runtime.manifest.title || "GameAnalysis 图片画廊",
    backgroundColor: "#171717",
    webPreferences: {
      contextIsolation: true,
      nodeIntegration: false,
      sandbox: false,
      preload: path.join(__dirname, "preload.js")
    }
  });
  mainWindow.webContents.setWindowOpenHandler(() => ({ action: "deny" }));

const state = {
  manifest: null,
  rows: [],
  query: "",
  category: "all",
  sort: "",
  page: 1,
  pageSize: 0,
  previewIndex: -1
};

const $ = (id) => document.getElementById(id);

function normalize(text) {
  return String(text || "").toLowerCase();
}

function area(item) {
  return Number(item.width || 0) * Number(item.height || 0);
}

function categories(rows) {
  return ["all", ...Array.from(new Set(rows.map((item) => item.category || "未分类"))).sort()];
}

function optionElement(value, label) {
  const option = document.createElement("option");
  option.value = String(value);
  option.textContent = String(label);
  return option;
}

function chipElement(label) {
  const chip = document.createElement("span");
  chip.className = "chip";
  chip.textContent = String(label);
  return chip;
}

function filteredRows() {
  const q = normalize(state.query);
  const rows = state.rows.filter((item) => {
    const categoryOk = state.category === "all" || item.category === state.category;
    const text = `${item.name} ${item.relative_path} ${item.category} ${item.source_label}`;
    return categoryOk && (!q || normalize(text).includes(q));
  });
  rows.sort((a, b) => {
    if (state.sort === "area_desc") return area(b) - area(a) || a.relative_path.localeCompare(b.relative_path);
    if (state.sort === "area_asc") return area(a) - area(b) || a.relative_path.localeCompare(b.relative_path);
    if (state.sort === "size_desc") return Number(b.size_bytes || 0) - Number(a.size_bytes || 0);
    return a.relative_path.localeCompare(b.relative_path);
  });
  return rows;
}

function populatePageSizeOptions(ui) {
  const configuredSizes = Array.isArray(ui.page_sizes)
    ? ui.page_sizes.map((value) => Number(value)).filter((value) => Number.isFinite(value) && value > 0)
    : [];
  const pageSizes = configuredSizes.length ? configuredSizes : [Math.max(1, state.rows.length || 1)];
  const defaultPageSize = Number(ui.default_page_size || pageSizes[0]);
  $("pageSize").replaceChildren(...pageSizes.map((size) => optionElement(size, `每页 ${size}`)));
  state.pageSize = pageSizes.includes(defaultPageSize) ? defaultPageSize : pageSizes[0];
  $("pageSize").value = String(state.pageSize);
}

function populateCategoryOptions() {
  $("category").replaceChildren(
    ...categories(state.rows).map((category) =>
      optionElement(category, category === "all" ? "全部分类" : category)
    )
  );
}

function itemById(id) {
  return state.rows.find((item) => item.id === id);
}

function openPreview(id) {
  const item = itemById(id);
  if (!item) return;
  state.previewIndex = state.rows.findIndex((row) => row.id === id);
  $("previewTitle").textContent = item.name;
  $("previewMeta").textContent = `${item.width}x${item.height} · ${item.category} · ${item.relative_path}`;
  $("previewImage").src = item.source_url;
  $("previewImage").alt = item.name;
  $("previewOverlay").hidden = false;
  document.body.classList.add("preview-open");
  document.querySelectorAll(".card.active").forEach((card) => card.classList.remove("active"));
  document.querySelector(`[data-card-id="${CSS.escape(item.id)}"]`)?.classList.add("active");
}

function closePreview() {
  $("previewOverlay").hidden = true;
  $("previewImage").removeAttribute("src");
  document.body.classList.remove("preview-open");
  document.querySelectorAll(".card.active").forEach((card) => card.classList.remove("active"));
}

function currentPreviewItem() {
  return state.rows[state.previewIndex] || null;
}

function cardElement(item) {
  const article = document.createElement("article");
  article.className = "card";
  article.dataset.cardId = item.id;

  const thumbButton = document.createElement("button");
  thumbButton.className = "thumb";
  thumbButton.type = "button";
  thumbButton.dataset.id = item.id;
  const image = document.createElement("img");
  image.loading = "lazy";
  image.src = item.thumb_url;
  image.alt = item.name || "";
  thumbButton.append(image);

  const info = document.createElement("div");
  info.className = "info";
  const name = document.createElement("div");
  name.className = "name";
  name.textContent = item.name || "";
  const chips = document.createElement("div");
  chips.className = "chips";
  chips.append(
    chipElement(`${item.width}x${item.height}`),
    chipElement(item.category || "未分类"),
    chipElement(item.has_alpha ? "Alpha" : "Opaque")
  );
  const pathText = document.createElement("div");
  pathText.className = "path";
  pathText.textContent = item.relative_path || "";
  info.append(name, chips, pathText);

  article.append(thumbButton, info);
  return article;
}

function render() {
  const rows = filteredRows();
  const pageCount = Math.max(1, Math.ceil(rows.length / state.pageSize));
  state.page = Math.min(Math.max(1, state.page), pageCount);
  const start = (state.page - 1) * state.pageSize;
  const pageRows = rows.slice(start, start + state.pageSize);
  $("filtered").textContent = rows.length.toLocaleString();
  $("pageInfo").textContent = `${state.page} / ${pageCount}`;
  $("empty").hidden = rows.length > 0;
  const fragment = document.createDocumentFragment();
  pageRows.forEach((item) => fragment.append(cardElement(item)));
  $("grid").replaceChildren(fragment);
  $("prev").disabled = state.page <= 1;
  $("next").disabled = state.page >= pageCount;
}

async function init() {
  state.manifest = await window.galleryBridge.loadManifest();
  state.rows = state.manifest.items || [];
  const ui = state.manifest.ui || {};
  $("sort").value = ui.default_sort || $("sort").options[0]?.value || "";
  state.sort = $("sort").value;
  populatePageSizeOptions(ui);
  $("title").textContent = state.manifest.title || "图片画廊";
  $("total").textContent = state.rows.length.toLocaleString();
  populateCategoryOptions();
  render();
}

$("grid").addEventListener("click", (event) => {
  const trigger = event.target.closest("[data-id]");

});

$("search").addEventListener("input", (event) => {

});

```powershell
param(
  [string]$SkillRoot = "",
  [string]$Version = "1.0.0"
)

$ErrorActionPreference = "Stop"
$env:PYTHONIOENCODING = "utf-8"
[Console]::OutputEncoding = [Text.Encoding]::UTF8
$OutputEncoding = [Text.Encoding]::UTF8
chcp 65001 > $null

if ([string]::IsNullOrWhiteSpace($SkillRoot)) {
  if ([string]::IsNullOrWhiteSpace($PSScriptRoot)) {
    throw "SkillRoot was not provided and PSScriptRoot is empty. Pass -SkillRoot explicitly."
  }
  $SkillRoot = Split-Path -Parent $PSScriptRoot
}

$templateDir = Join-Path $SkillRoot "assets\image-gallery-viewer-src"
$targetDir = Join-Path $SkillRoot ("built-in-tools\GameImageGallery_{0}" -f $Version)
$workDir = Join-Path $SkillRoot "tools\_build\GameImageGallery"

function Invoke-Npm {
  param(
    [Parameter(Mandatory = $true)]
    [string[]]$Arguments
  )

  $npmCommand = Get-Command "npm.cmd" -ErrorAction SilentlyContinue
  if (-not $npmCommand) {
    $npmCommand = Get-Command "npm" -ErrorAction Stop
  }
  & $npmCommand.Source @Arguments
}

if (-not (Test-Path -LiteralPath $templateDir)) {
  throw "Cannot find Electron image gallery template: $templateDir"
}

New-Item -ItemType Directory -Force -Path $workDir | Out-Null
Get-ChildItem -LiteralPath $templateDir | Copy-Item -Destination $workDir -Recurse -Force

Push-Location $workDir
try {
  if ($env:NODE_OPTIONS -notmatch "--use-system-ca") {
    $env:NODE_OPTIONS = (($env:NODE_OPTIONS, "--use-system-ca") -join " ").Trim()
  }
  Invoke-Npm @("install")
  Invoke-Npm @("run", "dist")
}
finally {
  Pop-Location
}

$portable = Get-ChildItem -LiteralPath (Join-Path $workDir "dist") -Filter "*.exe" -File |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $portable) {
  throw "Electron build finished but no .exe was found under '$workDir\dist'."
}

New-Item -ItemType Directory -Force -Path $targetDir | Out-Null
$target = Join-Path $targetDir "GameImageGallery.exe"
Copy-Item -LiteralPath $portable.FullName -Destination $target -Force
Write-Output $target
```
