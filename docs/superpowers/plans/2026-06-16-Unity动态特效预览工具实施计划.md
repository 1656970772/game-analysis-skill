# Unity 动态特效预览工具 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 GameAnalysis 增加 Unity 动态特效预览工具：像图片画廊和模型预览一样使用固定 EXE + 每项目 BAT + manifest，同时能动态播放 Unity VFX 并生成 Unity 可回导工程片段。

**Architecture:** 采用配置驱动的 Unity VFX adapter 架构。Python 第一版只读取 UnityPy 全量可读资源索引，生成 VFX manifest、reconstruction JSON、Unity 回导目录、BAT 和报告摘要；Electron/Three.js 固定工具只读加载 manifest 并播放重建特效；Unity 回导片段由 `Assets/GameAnalysisVfxPreview/` 承载，不修改源游戏目录。

**Tech Stack:** Python 3 + pytest、PowerShell 5.1+、Electron、Three.js、electron-builder、Windows BAT、Unity ParticleSystem 文本 prefab/bootstrap 片段。

## 实施约束

- 只做 Unity 第一版；Unreal/Cocos 只保留 `engine` 字段和 adapter 边界，不写实现。
- 第一版输入只支持 UnityPy 全量可读资源索引；AssetRipper 只作为后续 adapter 扩展，不进入本计划验收。
- 不硬编码游戏名、中文项目名、path id、技能名以外的绝对路径；所有路径和状态枚举进入配置。
- 固定 EXE 位于 Skill `built-in-tools/GameVfxViewer_1.0.0/`，每个 study-root 只生成 BAT 和索引，不复制 EXE。
- `1.分类资源/特效/` 继续只放最终分类资源；manifest、reconstruction、Unity 回导片段、errors 全部放 `4.临时目录/中间索引/VFX预览/`。
- Unity 回导片段只引用回导目录内资源，不引用源游戏安装目录。
- 所有 PowerShell 命令注入 UTF-8 设置；中文路径用 `-LiteralPath`。

## 审查修订门禁

以下门禁来自计划审查，执行时必须优先满足；任何旧片段与本节冲突时，以本节为准。

- Adapter 边界：`build_vfx_preview_manifest.py` 和 `export_unity_vfx_reconstruction.py` 不直接写 Unity 类型分支；Unity 逻辑必须在 `scripts/vfx_adapters/unity.py`，通过 `EngineAdapter` contract 调用。
- 状态机：manifest 构建阶段只能写 `pending`、`resource_only`、`unsupported` 或 `failed`；只有 reconstruction 文件已生成且 viewer runtime 能加载时才允许 `preview_status` 升级为 `ready` 或 `partial`；只有 Unity 回导目录包含 prefab、metadata、bootstrap 和资源引用时才允许 `unity_export_status` 升级为 `ready` 或 `partial`。
- 依赖解析：第一版必须实现 `ParticleSystem -> ParticleSystemRenderer -> Material -> Texture2D/Sprite` 的可测试链路；没有依赖时写 `warnings`，不能静默返回空数组并标记 ready。
- 动态预览：viewer 不能只画随机圆点。第一版必须加载 reconstruction，使用贴图或降级材质颜色渲染 billboard 粒子，应用 emission、lifetime、speed、size、color、texture sheet、TrailRenderer 和 LineRenderer 的最小行为，并验证 canvas 非空和播放推进后的像素变化。
- Unity 回导：prefab/bootstrap 不能是空壳。Bootstrap 必须读取 metadata JSON 并把 main、emission、shape、renderer 基础参数写入 ParticleSystem；prefab 必须包含 ParticleSystem、Bootstrap、metadata 引用和基础材质/贴图引用。
- 路径安全：manifest 内优先写相对 `preview_relative_path` / `unity_export_relative_path`；Electron 主进程只能读取 `study-root`、`reconstructed-dir`、`preview-cache-dir`、`unity-export-dir` allowlist 内文件。
- 验证强度：测试不能只查文件和字符串存在；必须包含状态迁移、依赖关联、schema 校验、canvas 像素变化、播放暂停、时间轴推进、错误降级和固定样例端到端链路。

```python
from __future__ import annotations

import hashlib
import json
import re
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Iterable


SKILL_ROOT = Path(__file__).resolve().parents[1]
DEFAULT_CONFIG = SKILL_ROOT / "references" / "vfx-preview-config.json"
PATH_SEPARATOR_RE = re.compile(r"[\\/]+")
WINDOWS_DRIVE_RE = re.compile(r"^[A-Za-z]:")


@dataclass(frozen=True)
class VfxPaths:
    report_dir: Path
    overview: Path
    unitypy_index: Path
    unitypy_root: Path
    classified_vfx_dir: Path
    preview_index_dir: Path
    manifest: Path
    errors_jsonl: Path
    reconstructed_dir: Path
    preview_cache_dir: Path
    unity_export_dir: Path
    launcher: Path


def as_relative_path(value: str) -> Path:
    if not isinstance(value, str) or not value:
        raise ValueError("config path must be a non-empty string")
    if value.startswith(("/", "\\")) or WINDOWS_DRIVE_RE.match(value):
        raise ValueError(f"absolute config paths are not allowed: {value}")
    parts = PATH_SEPARATOR_RE.split(value)
    if any(part in {"", ".", ".."} for part in parts):
        raise ValueError(f"config path must not contain traversal or empty parts: {value}")
    return Path(*parts)


def load_vfx_config(config_path: Path | None = None) -> dict[str, Any]:
    path = config_path or DEFAULT_CONFIG
    data = json.loads(path.read_text(encoding="utf-8"))
    required = ["schema_version", "tool", "launcher", "paths", "manifest", "state_machine", "adapter", "unity_export", "name_keyword_rules", "limits"]
    missing = [key for key in required if key not in data]
    if missing:
        raise ValueError(f"VFX preview config missing keys: {', '.join(missing)}")
    for key in ["directory", "source_template_dir"]:
        as_relative_path(str(data["tool"][key]))
    for key in [
        "report_dir",
        "overview_name",
        "unitypy_index",
        "unitypy_root",
        "classified_vfx_dir",
        "preview_index_dir",
        "manifest_name",
        "errors_name",
        "reconstructed_dir",
        "preview_cache_dir",
        "unity_export_dir",
    ]:
        as_relative_path(str(data["paths"][key]))
    for key in [
        "asset_root",
        "prefabs_dir",
        "materials_dir",
        "textures_dir",
        "meshes_dir",
        "animations_dir",
        "scripts_dir",
        "metadata_dir",
        "bootstrap_script_name",
    ]:
        as_relative_path(str(data["unity_export"][key]))
    if "/" in data["tool"]["exe_name"] or "\\" in data["tool"]["exe_name"]:
        raise ValueError("tool.exe_name must be a filename")
    if "/" in data["launcher"]["bat_name"] or "\\" in data["launcher"]["bat_name"]:
        raise ValueError("launcher.bat_name must be a filename")
    return data


def resolve_path(root: Path, relative_value: str) -> Path:
    return root / as_relative_path(relative_value)


def ensure_inside_root(path: Path, root: Path) -> Path:
    resolved = path.resolve(strict=False)
    resolved_root = root.resolve(strict=False)
    try:
        resolved.relative_to(resolved_root)
    except ValueError as exc:
        raise ValueError(f"path is outside study-root: {resolved}") from exc
    return resolved


def vfx_paths(study_root: Path, config: dict[str, Any]) -> VfxPaths:
    root = study_root.resolve(strict=False)
    paths = config["paths"]
    report_dir = ensure_inside_root(resolve_path(root, paths["report_dir"]), root)
    preview_index_dir = ensure_inside_root(resolve_path(root, paths["preview_index_dir"]), root)
    manifest = ensure_inside_root(preview_index_dir / as_relative_path(paths["manifest_name"]), root)
    errors = ensure_inside_root(preview_index_dir / as_relative_path(paths["errors_name"]), root)
    return VfxPaths(
        report_dir=report_dir,
        overview=ensure_inside_root(report_dir / paths["overview_name"], root),
        unitypy_index=ensure_inside_root(resolve_path(root, paths["unitypy_index"]), root),
        unitypy_root=ensure_inside_root(resolve_path(root, paths["unitypy_root"]), root),
        classified_vfx_dir=ensure_inside_root(resolve_path(root, paths["classified_vfx_dir"]), root),
        preview_index_dir=preview_index_dir,
        manifest=manifest,
        errors_jsonl=errors,
        reconstructed_dir=ensure_inside_root(preview_index_dir / as_relative_path(paths["reconstructed_dir"]), root),
        preview_cache_dir=ensure_inside_root(preview_index_dir / as_relative_path(paths["preview_cache_dir"]), root),
        unity_export_dir=ensure_inside_root(preview_index_dir / as_relative_path(paths["unity_export_dir"]), root),
        launcher=ensure_inside_root(report_dir / config["launcher"]["bat_name"], root),
    )


def stable_vfx_id(source_file: str, path_id: str, name: str) -> str:
    payload = f"{source_file}\n{path_id}\n{name}".lower().encode("utf-8")
    return hashlib.sha256(payload).hexdigest()[:16]


def write_json_utf8(path: Path, payload: dict[str, Any]) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(payload, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")


def write_jsonl_utf8(path: Path, rows: Iterable[dict[str, Any]]) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("w", encoding="utf-8", newline="\n") as handle:
        for row in rows:
            handle.write(json.dumps(row, ensure_ascii=False) + "\n")

        var ps = GetComponent<ParticleSystem>();
        if (ps == null)
        {
            ps = gameObject.AddComponent<ParticleSystem>();
        }
        var json = JsonUtility.FromJson<GameAnalysisVfxMetadata>(metadata.text);
        var main = ps.main;
        main.duration = Mathf.Max(0.01f, json.duration);
        main.loop = json.looping;
        main.startSpeed = json.startSpeed;
        main.startSize = json.startSize;
        main.startLifetime = json.startLifetime;
        main.maxParticles = Mathf.Max(1, json.maxParticles);
        var emission = ps.emission;
        emission.enabled = true;
        emission.rateOverTime = json.rateOverTime;
        var renderer = GetComponent<ParticleSystemRenderer>();
        if (renderer == null) renderer = gameObject.AddComponent<ParticleSystemRenderer>();
        if (material != null) renderer.sharedMaterial = material;
    }

    [System.Serializable]
    private sealed class GameAnalysisVfxMetadata
    {
        public float duration = 1f;
        public bool looping = true;
        public float startLifetime = 1f;
        public float startSpeed = 1f;
        public float startSize = 1f;
        public int maxParticles = 1000;
        public float rateOverTime = 10f;
    }
}
"""
```

Prefab 文本可以保持最小 YAML，但必须包含可被 Unity 识别的 GameObject、Transform、ParticleSystemRenderer、ParticleSystem 和 Bootstrap MonoBehaviour 占位，并在 `Metadata/<id>.json` 中保留完整 reconstruction。若无法可靠写入 MonoBehaviour fileID，`unity_export_status` 必须为 `partial`，不能标记 `ready`。

from __future__ import annotations

import argparse
import json
from pathlib import Path

try:
    from scripts.vfx_preview_common import load_vfx_config, vfx_paths
except ModuleNotFoundError:
    import sys
    sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
    from scripts.vfx_preview_common import load_vfx_config, vfx_paths


START = "<!-- GameAnalysis:VFX_PREVIEW_SUMMARY:start -->"
END = "<!-- GameAnalysis:VFX_PREVIEW_SUMMARY:end -->"


def managed_block(manifest_path: Path, items: list[dict]) -> str:
    dynamic = sum(1 for item in items if item.get("preview_status") in {"ready", "partial"})
    ready = sum(1 for item in items if item.get("reconstruction_status") == "full")
    partial = sum(1 for item in items if item.get("reconstruction_status") == "partial")
    resource_only = sum(1 for item in items if item.get("preview_status") == "resource_only")
    unity_ready = sum(1 for item in items if item.get("unity_export_status") == "ready")
    failed = sum(1 for item in items if item.get("preview_status") == "failed")
    lines = [
        START,
        "## 特效预览摘要",
        "",
        f"- Manifest：`{manifest_path}`",
        f"- 动态可预览：{dynamic}",
        f"- 完整动态重建：{ready}",
        f"- 部分动态重建：{partial}",
        f"- 仅资源关联：{resource_only}",
        f"- Unity 回导就绪：{unity_ready}",
        f"- 失败：{failed}",
        "",
        END,
    ]
    return "\n".join(lines)


def update_summary(study_root: Path, config_path: Path, manifest_path: Path | None = None) -> None:
    config = load_vfx_config(config_path)
    paths = vfx_paths(study_root, config)
    target_manifest = manifest_path or paths.manifest
    manifest = json.loads(target_manifest.read_text(encoding="utf-8-sig")) if target_manifest.is_file() else {"items": []}
    block = managed_block(target_manifest, manifest.get("items", []))
    original = paths.overview.read_text(encoding="utf-8") if paths.overview.is_file() else "# 研究总览\n"
    if START in original and END in original:
        before = original.split(START, 1)[0].rstrip()
        after = original.split(END, 1)[1].lstrip()
        updated = before + "\n\n" + block + "\n\n" + after
    else:
        updated = original.rstrip() + "\n\n" + block + "\n"
    paths.overview.parent.mkdir(parents=True, exist_ok=True)
    paths.overview.write_text(updated, encoding="utf-8")

const { app, BrowserWindow, ipcMain, shell } = require('electron');
const fs = require('fs');
const path = require('path');

function parseArgs(argv) {
  const args = {};
  for (let i = 0; i < argv.length; i += 1) {
    const item = argv[i];
    if (item.startsWith('--')) {
      args[item.slice(2)] = argv[i + 1] && !argv[i + 1].startsWith('--') ? argv[++i] : true;
    }
  }
  return args;
}

const cli = parseArgs(process.argv.slice(1));

function readJson(filePath) {
  assertAllowed(filePath);
  return JSON.parse(fs.readFileSync(filePath, 'utf8'));
}

function isInside(child, parent) {
  const relative = path.relative(path.resolve(parent), path.resolve(child));
  return relative === '' || (!relative.startsWith('..') && !path.isAbsolute(relative));
}

function allowedRoots() {
  return [cli['study-root'], cli['reconstructed-dir'], cli['preview-cache-dir'], cli['unity-export-dir']]
    .filter(Boolean)
    .map((item) => path.resolve(item));
}

function assertAllowed(filePath) {
  const resolved = path.resolve(filePath);
  if (!allowedRoots().some((root) => isInside(resolved, root))) {
    throw new Error(`Refusing to read outside allowed VFX roots: ${resolved}`);
  }
  return resolved;
}

async function runSelfTest() {
  const manifest = readJson(cli.manifest);
  if (!Array.isArray(manifest.items)) throw new Error('manifest.items must be an array');
  const first = manifest.items.find((item) => item.preview_status === 'ready' || item.preview_status === 'partial');
  if (!first) throw new Error('manifest must contain at least one playable VFX item');
  const reconstructionPath = path.join(cli['reconstructed-dir'], path.basename(first.reconstruction_relative_path || first.reconstruction_path || ''));
  const reconstruction = readJson(reconstructionPath);
  if (!reconstruction.main || !reconstruction.emission || !reconstruction.renderer) {
    throw new Error('reconstruction must contain main, emission and renderer modules');
  }
  return { ok: true, itemCount: manifest.items.length, firstPlayable: first.id };
}

function createWindow() {
  const win = new BrowserWindow({
    width: 1400,
    height: 900,
    backgroundColor: '#111318',
    webPreferences: {

      contextIsolation: true,
      nodeIntegration: false
    }
  });

  canvasSignatureBeforePlay: 0,
  canvasSignatureAfterPlay: 0,
  playbackTime: 0

function constantValue(value, fallback) {
  if (!value) return fallback;
  if (value.mode === 'constant') return Number(value.constant);
  if (value.mode === 'random_between_two_constants') {
    return Number(value.min) + Math.random() * (Number(value.max) - Number(value.min));
  }
  return fallback;
}

async function loadTexture(textureRef) {
  if (!textureRef) return null;
  const image = new Image();
  image.src = await window.gameVfxViewer.resolveAssetUrl(textureRef);
  await image.decode();
  textureImage = image;
  return image;
}

function spawnParticle() {
  const main = reconstruction.main || {};
  const lifetime = constantValue(main.startLifetime, 1);
  const color = main.startColor && main.startColor.color ? main.startColor.color : [1, 1, 1, 1];
  particles.push({
    age: 0,
    lifetime,
    x: 0,
    y: 0,
    vx: (Math.random() - 0.5) * constantValue(main.startSpeed, 1),
    vy: -constantValue(main.startSpeed, 1),
    size: constantValue(main.startSize, 8),
    color,
    frame: 0
  });
}

function textureSheetAnimation(particle) {
  const module = reconstruction.textureSheetAnimation;
  if (!module || !module.enabled) return 0;
  const tiles = module.tiles || [1, 1];
  const frame = Math.floor((particle.age / particle.lifetime) * tiles[0] * tiles[1]);
  return frame % (tiles[0] * tiles[1]);
}

function drawTexturedParticle(ctx, particle) {
  const alpha = Math.max(0, 1 - particle.age / particle.lifetime) * particle.color[3];
  const px = ctx.canvas.width / 2 + particle.x * 40;
  const py = ctx.canvas.height / 2 + particle.y * 40;
  ctx.globalAlpha = alpha;
  if (textureImage) {
    const frame = textureSheetAnimation(particle);
    const module = reconstruction.textureSheetAnimation || {};
    const tiles = module.tiles || [1, 1];
    const sx = (frame % tiles[0]) * (textureImage.width / tiles[0]);
    const sy = Math.floor(frame / tiles[0]) * (textureImage.height / tiles[1]);
    const sw = textureImage.width / tiles[0];
    const sh = textureImage.height / tiles[1];
    ctx.drawImage(textureImage, sx, sy, sw, sh, px - particle.size, py - particle.size, particle.size * 2, particle.size * 2);
  } else {
    ctx.fillStyle = `rgba(${particle.color[0] * 255}, ${particle.color[1] * 255}, ${particle.color[2] * 255}, ${alpha})`;
    ctx.beginPath();
    ctx.arc(px, py, particle.size, 0, Math.PI * 2);
    ctx.fill();
  }
  ctx.globalAlpha = 1;
}

function updateTrailAndLine(particle) {
  if (reconstruction.trail && reconstruction.trail.enabled) {
    trailSegments.push({ x: particle.x, y: particle.y, age: 0 });
    trailSegments = trailSegments.filter((segment) => {
      segment.age += 1 / 60;
      return segment.age < 1;
    });
  }
  if (reconstruction.line && reconstruction.line.enabled) {
    lineRenderer = reconstruction.line;
  }
}

function sampleCanvasSignature(canvas) {
  const data = canvas.getContext('2d').getImageData(0, 0, canvas.width, canvas.height).data;
  let signature = 0;
  for (let i = 0; i < data.length; i += 97) signature = (signature + data[i]) % 65535;
  return signature;
}

function draw() {
  const canvas = document.getElementById('vfx-canvas');
  const ctx = canvas.getContext('2d');
  if (window.__gameVfxViewerState.canvasSignatureBeforePlay === 0) {
    window.__gameVfxViewerState.canvasSignatureBeforePlay = sampleCanvasSignature(canvas);
  }
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = '#151821';
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  for (const particle of particles) {
    drawTexturedParticle(ctx, particle);
    updateTrailAndLine(particle);
  }
  window.__gameVfxViewerState.canvasSignatureAfterPlay = sampleCanvasSignature(canvas);
}

function tick(now) {
  const dt = Math.min(0.05, (now - lastFrame) / 1000);
  lastFrame = now;
  if (playing && reconstruction) {
    time += dt;
    window.__gameVfxViewerState.playbackTime = time;
    const rate = constantValue(reconstruction.emission && reconstruction.emission.rateOverTime, 8);
    for (let i = 0; i < Math.ceil(rate * dt); i += 1) spawnParticle();
    particles = particles.filter((particle) => {
      particle.age += dt;
      particle.x += particle.vx * dt;
      particle.y += particle.vy * dt;
      return particle.age < particle.lifetime;
    });
    draw();
  }
  requestAnimationFrame(tick);
}

function Invoke-CdpWebSocket {
    param(
        [Parameter(Mandatory = $true)][string]$WebSocketUrl,
        [Parameter(Mandatory = $true)][hashtable]$Payload
    )

    $client = [System.Net.WebSockets.ClientWebSocket]::new()
    $uri = [Uri]$WebSocketUrl
    $client.ConnectAsync($uri, [Threading.CancellationToken]::None).GetAwaiter().GetResult()
    $json = $Payload | ConvertTo-Json -Depth 8 -Compress
    $sendBytes = [Text.Encoding]::UTF8.GetBytes($json)
    $sendSegment = [ArraySegment[byte]]::new($sendBytes)
    try {
        $client.SendAsync($sendSegment, [System.Net.WebSockets.WebSocketMessageType]::Text, $true, [Threading.CancellationToken]::None).GetAwaiter().GetResult()
        $buffer = New-Object byte[] 65536

## 计划自审

- 通用架构：计划采用 `EngineAdapter` contract、registry、Unity adapter、manifest、reconstruction schema、viewer、Unity exporter 分层；核心脚本不直接写 Unity 类型分支，没有针对 `鬼谷八荒`、`Amazing Cultivation Simulator` 或单个 path id 写死逻辑。
- 设计模式适配：沿用图片画廊和模型预览的固定 EXE + 项目 BAT + manifest + errors + GUI 验证模式；新增 Unity adapter、dependency resolver 和 exporter 作为可扩展边界。

- 简单性：第一版只做 UnityPy 输入的 Unity 动态预览和 Unity 回导；不实现 AssetRipper 输入、不实现多引擎、不做完整 Unity runtime、不自动启动 Unity Editor。
- 验证标准：每个任务都有失败测试、实现、通过测试和 commit；最终验收包含 Python 测试、依赖关联测试、状态迁移测试、fixed sample 端到端、固定 EXE 构建、self-test、canvas 像素变化 GUI 验证和 study-root 产物检查。
